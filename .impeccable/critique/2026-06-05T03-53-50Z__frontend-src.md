## Anti-Patterns Verdict

**LLM assessment:** Functional HR admin tool, not a marketing page. Still reads partly AI-scaffolded: repeated uppercase section eyebrows, identical metric-card grids, side-accent stripes on toasts and source cards, and a second "product within a product" Datamart skin with gradient avatars. Familiar SaaS patterns (teal + slate-900 sidebar) are appropriate for the category but lack tenant-specific personality.

**Deterministic scan (6 findings):**
- `Toast.tsx:43` — `border-l-4` side-tab accent
- `index.css:55` — `transition: width`
- `datamart-page.css:1001,1091` — `transition: width` (×2)
- `DatabaseManager.tsx:181` — gray text on teal-100 (unrouted legacy page)
- `EtlSources.tsx:146` — `text-slate-400` on `hover:bg-red-50` delete button

**Browser overlays:** Not available — no browser automation in this session. Dev server appears active (Vite HMR) but injection was not attempted.

## Overall Impression

Solid data-tool foundation with clear information architecture and reusable report primitives. The biggest gap is **experience fragmentation**: HR reports feel like one product, Datamart feels like another, and shared patterns (loading, empty states, motion) are inconsistent. The HR Dashboard tries to be everything at once.

## Page-by-Page Review

### Shared shell — `Layout.tsx`
**Works:** Grouped sidebar (Dashboard / Employment / Operations / Platform), icons with text labels, active state, Datamart overflow handling.  
**Issues:** Empty 56px header when no tenant logo — no product name fallback. Footer "v2.0 · Employment marts" is internal dev copy. 14 nav links create scan cost despite grouping. No user/tenant indicator or sign-out.

### `/auth` — AuthLaunch
**Works:** Focused loading and error states; actionable recovery copy.  
**Issues:** Generic centered card; no branding from `tenantBranding` on failure path. Spinner-only loading (no status steps).

### `/hr/dashboard` — HRDashboard
**Works:** Period filter placement; semantic metric grouping.  
**Issues:** **P1** 15+ metric cards above fold — cognitive wall. Uppercase section headers on every block (Workforce, Compensation, Attendance & leave, Performance). Text-only loading. Overlaps dedicated report routes without deep links.

### Employment reports — Workforce, Employees, Salary Bands, Lifecycle, Headcount, Turnover
**Works:** Consistent header + PeriodFilter + MetricCard + DataTable pattern; Employees has pagination and error state.  
**Issues:** **P1** Workforce vs Headcount near-duplicate KPIs/tables — IA confusion. **P2** Identical card-grid template on every page (flat hierarchy). **P2** Loading is pulse text, not skeleton rows/cards. **P2** Empty tables say "No data." with no next step.

### Operations reports — Payroll, Attendance, Leave, Performance
**Works:** Payroll multi-section layout suits data density; compliance labels humanized.  
**Issues:** **P2** Payroll repeats uppercase section pattern. **P2** No export on standard reports (only Customized Reports). Period semantics differ page to page (some tables ignore selected period).

### `/hr/custom-reports` + `/hr/custom-reports/:viewName`
**Works:** Strong empty state (dbt guidance); export loading states; full-page preview with back link.  
**Issues:** **P2** List row actions wrap awkwardly on narrow widths. **P3** Title weight differs (`font-semibold` vs `font-bold` elsewhere).

### `/datamart/chat` + `/datamart/templates/:id` — DatamartWorkspace
**Works:** Richest interaction design; sidebar search/grouping; streaming chat; workspace shell.  
**Issues:** **P1** Separate design tokens (`--dm-accent` blue vs app teal) breaks consistency. **P1** Sidebar cognitive load (templates + grouped sessions + inline edit). **P2** Gradient avatar inline styles feel decorative, not stateful. **P2** `datamart-page.css` animations lack `prefers-reduced-motion`. **P2** Width transitions flagged by detector.

### `/etl/control` — ETLControl
**Works:** Source summary banner with link; run polling; failure toast + inline detail; watermark explanation.  
**Issues:** **P2** Native `<select>` and underlined "Clear stuck runs" look secondary vs destructive-adjacent. **P2** Full Load option needs stronger guard/confirm. **P3** Uppercase table headers at `text-xs`.

### `/settings/etl-sources` — EtlSources
**Works:** Progressive disclosure in add modal; test-before-save; primary badge; cross-link to ETL Control.  
**Issues:** **P1** Source cards use `w-1` colored side stripe (AI tell). **P2** Delete hover: gray icon on red-50 (detector). **P2** Modal-heavy add flow (product register prefers inline where possible).

## Priority Issues

**[P1] Dual design systems (HR vs Datamart)**  
Why: Users perceive two apps; trust and learnability suffer.  
Fix: Unify tokens (teal primary, one accent), shared components for buttons/cards/toasts, remove blue gradient accents or demote to avatars only.  
Command: `/impeccable distill datamart workspace`

**[P1] HR Dashboard metric overload**  
Why: 15+ KPIs with equal visual weight; no clear primary story.  
Fix: Show 4–6 headline metrics + links to reports; collapse sections or use tabs.  
Command: `/impeccable layout HR dashboard`

**[P1] Loading states are text pulses, not skeletons**  
Why: Layout shift; feels unfinished vs Datamart/ETL polish.  
Fix: Skeleton MetricCards and table rows via shared primitive.  
Command: `/impeccable polish HR report pages`

**[P1] Side-stripe accents (Toast, EtlSources cards)**  
Why: Detector-flagged AI slop; inconsistent with clean bordered cards elsewhere.  
Fix: Full border tint or icon-led status, remove `border-l-4` and `w-1` stripes.  
Command: `/impeccable quieter Toast and EtlSources cards`

**[P2] Overlapping Workforce / Headcount reports**  
Why: Jordan cannot tell which page to use.  
Fix: Merge or differentiate (charts vs roster); breadcrumb context.  
Command: `/impeccable shape employment reports IA`
