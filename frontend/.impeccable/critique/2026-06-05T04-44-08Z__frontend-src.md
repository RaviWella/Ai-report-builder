## Priority Issues

**[P1] Datamart sidebar cognitive load**  
Why: Templates, chats, groups, and inline edits compete in one narrow column; first-time users cannot build a mental model quickly.  
Fix: Collapse templates by default, separate "Library" vs "Sessions" tabs, or move template management to a dedicated route.  
Command: `/impeccable shape datamart sidebar`

**[P1] No contextual help for platform concepts**  
Why: Watermarks, extractor profiles, grounding confirm, and dbt custom reports assume operator knowledge; violates PRODUCT principle 5 for secondary IT persona.  
Fix: Inline dismissible hints on ETL watermarks, ETL sources add modal, and Datamart grounding; link to short task docs.  
Command: `/impeccable onboard platform surfaces`

**[P2] Empty states stop at "no data"**  
Why: Users hit dead ends without knowing whether to change period, run ETL, or open another report.  
Fix: One-line next action per empty table (change period, open ETL Control, check sources).  
Command: `/impeccable clarify HR report empty states`

**[P2] Power-user efficiency gaps**  
Why: Payroll analysts repeating month-end work cannot export employee/payroll tables or navigate by keyboard.  
Fix: Export on Employees/Payroll tables; command palette or shortcut stubs for period change and sidebar jump.  
Command: `/impeccable adapt HR report tables`

**[P2] Custom reports loading inconsistency**  
Why: Spinner text while the rest of the app uses skeletons; minor layout shift.  
Fix: `ReportTableSkeleton` or row skeleton on customized reports list.  
Command: `/impeccable polish customized reports`
