HR Datamart Entity-Relationship Overview

Branch: mart_checks  ·  Warehouse: PostgreSQL per tenant (hrm_wh_{tenant_id})  ·  Pattern: Medallion architecture + Kimball star schema (conformed dimensions, surrogate keys)

DIM — Dimension FACT — Atomic grain MART — BI-ready aggregate VIEW — Semantic / legacy

Control plane: hr_control — ETL run log, watermarks, source registry.

Bronze — hr_raw Staging tables from MintHRM source (stg_*). Includes stg_company_hierarchy_individual (org-chart superior), stg_payroll_salary_bank_data, and related payroll staging. Loaded by tenant ETL.
Silver / Gold — hr dbt dimensions, facts, and marts. Kimball-style stars with *_sk surrogate keys.
Semantic — hr_semantic Stable vw_* views for APIs and reports. Hides physical mart churn.
Conformed bus matrix dim_employee is shared across Enterprise HR and Payroll Phase 6. Payroll adds dim_payroll_period, dim_payroll_group, dim_canonical_pay_item.

Source: backend/dbt_project/hr_mart/models/marts/ and models/semantic/ · Generated for executive / architecture review.
